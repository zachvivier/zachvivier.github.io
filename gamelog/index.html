Gamelog

Gamelog is a web app for keeping track of the games you play: ratings, notes, where and when you played, a wishlist, and patch notes for your Steam games. A scratchpad lets you type or draw quick notes and save them to a game.

Where it runs

Gamelog began as an iPhone app on TestFlight. It is no longer there. It now runs as a web app at home on my Tailnet, saved to the iPhone Home Screen. Here is why I moved it.

If you would like to run it yourself, email zachvivierdev@gmail.com. I can share the source on GitHub.
