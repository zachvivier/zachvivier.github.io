Folding@home on My Framework

tl;dr

Folding@home lends spare computer power to disease research. Your computer downloads a small piece of a protein simulation, works on it, and sends the result back. Linus Tech Tips runs a Folding Month every year, and this one runs from November 1 to December 6. I wanted my Framework desktop on the team.

The CPU was easy, the GPU wasn’t

I got the client installed on October 19. I gave it 24 of the machine’s 32 threads: 23 to fold and one to feed the graphics chip. CPU folding worked on the first try. The GPU took three failed work units. One needed a missing library, and two crashed in the same folding core. A unit on a newer core finally ran, at 96% GPU use and about two hours per unit.

Folding while I sleep

I don’t want the fans going while I work, so it folds from 11 PM to 8 AM. A local dashboard I use on my Tailnet got a Folding tab with my points, the nightly schedule, and Fold, Finish, and Pause buttons.

The first time I resumed after a pause, a work unit was already at 47%. I expected it to start over, so I checked the client log. The CPU unit picked up from its last checkpoint and lost nothing. The GPU saves every 5%, so a pause can cost about seven minutes of work. The real cost is bonus points, because the bonus clock keeps running while folding is paused.

A loading icon for it

Jakub Krehel and Paul Faivret’s loading.dev is a library of small loading spinners, and it had no double helix. So I made one.

Six pairs of dots swing side to side. Each dot grows as it turns toward you and fades as it turns away, so flat dots read as a twist. It’s plain SVG and CSS, it takes the color of the text around it, and with reduced motion turned on it holds a still frame.

I first built it into my fork of the library, where all 188 of its tests passed. It now has its own repo, so you can use it with one CSS file, a single animated SVG, or a React component. One caveat: a double helix is DNA, and Folding@home simulates proteins, so a folding coil would be more accurate.

What’s next

Before November 1, I want to finish ten work units, which unlocks bonus points for the event. Then the Framework folds every night through December 6. The helix may go into that dashboard next.

If you have a spare GPU, get the client from foldingathome.org and join the Linus Tech Tips team, 223518.
