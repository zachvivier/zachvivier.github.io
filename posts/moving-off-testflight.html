Moving My Apps Off TestFlight

tl;dr

Over the last two months I built three iPhone apps with Claude: Gamelog, Cozy Reader, and Cozy Crafter. Each one went to TestFlight, and I invited anyone to try them. This month I retired all three. They now run as web apps on the Framework desktop in my house.

Why I left

These apps have two users: my wife and me. To keep them on our phones, I needed an Apple Developer membership, which costs $99 a year. TestFlight builds also stop working after 90 days, so each app needed a new upload every few months, used or not. That is a lot of upkeep for two people.

I had also started the App Store listing for Gamelog. The more of it I filled in, the less I wanted to run a public app.

What replaced them

Each app is now a web page and a small Python server. The server uses only what comes with Python, so there is nothing to install or update around it. It runs on my Framework and answers only on my Tailnet, the private network Tailscale makes between our devices. Nothing is open to the internet.

On the iPhone, you open the page in Safari and choose Add to Home Screen. After that it has its own icon and opens full screen like any other app. It keeps a copy of the data on the phone, so it still opens when the phone is off the Tailnet. Changes wait and sync when the server is back in reach.

Moving over was simple. The iPhone apps could already save a backup file, and the web apps read that same file. They can write it too, so there is a way back.

What got better

In the Cozy Crafter post I said syncing between devices could come later. It came with the move. The server holds the data, so her phone and iPad show the same projects, themes included.

Shipping a fix is faster too. I change a file on the Framework, and the fix is there the next time the app opens. There is no build to archive, no upload, and no review to wait for.

I also don’t need a Mac anymore. The iPhone apps could only be built on one, in Xcode. The web apps live on the Framework, and I can work on them remotely from any of my other machines running Linux.

A bonus: my wife is on the Tailnet

To use her apps, my wife’s phone had to join my Tailnet. I set that up for Cozy Reader and Cozy Crafter, but it opened up everything else I run at home. We can now use other local apps together. The first is Filament Shelf, my inventory of the filament for our 3D printer. She can check what colors we have before she plans a print.

What I gave up

Nobody else can install them. A TestFlight link works for anyone, and an app on my Tailnet works for the people on my Tailnet.

Some iPhone features are gone: widgets, Live Activities, Siri, and haptics. So far neither of us has missed them.

I also said her data would stay on her phone, with no server. Now there is a server. It sits in our house and nobody else can reach it, so I think the promise still holds. But a backup is now my job, not iCloud’s.

If you want one

The betas are closed. If you would like to run one of these yourself, email zachvivierdev@gmail.com and say which app. I can share the source on GitHub. You need a computer that stays on, and Tailscale.
